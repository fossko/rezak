## Соответствие постановке и спецификации

Исходная версия использована для сверки предлагаемого решения с текущими маршрутами и контрактами. Реализация по спецификации ещё не представлена. Итог приёмки реализации открыт.

## Корректность и безопасность

1. **P2 · R1. Ненадёжная проверка принадлежности пути.** Строковый префикс может принять соседний каталог с похожим именем за содержимое разрешённой папки. Читаемые файлы при этом могут быть выданы сервером. [Раздача сборки](../../serve.mjs#L25), [раздача моделей в Vite](../../vite.config.ts#L19).
2. **P2 · R2–R4. Проверка данных проекта применяется только при обновлении.** При создании ветка PUT сохраняет данные до проверки встроенного медиа. Ограничение тела запроса не задаёт суммарный предел хранения, что создаёт риск исчерпания диска сервера рабочих пространств. [Обработчик PUT](../../server/workspace-server.mjs#L392), [политика безопасности](../../SECURITY.md).
3. **P2 · R4. Тайм-аут преждевременно освобождает очередь записи.** `withTimeout` завершает гонку промисов, пока исходная операция может продолжаться. Если запись выполняется дольше лимита, следующий запрос в том же пространстве может прочитать прежнее состояние. Последующая запись может потерять одно из обновлений, а расчёт квоты будет опираться на устаревший снимок. Это нарушает контракт эксклюзивной очереди, описанный в коде. [Тайм-аут и очередь](../../server/workspace-server.mjs#L60).

Ревью выполнено одним агентом в отдельных проходах по постановке и коду. Выводы основаны на чтении исходников. Предыдущий локальный прогон проверки типов, сканера секретов и сборки прошёл. Полный прогон тестов остановился при запуске `python3` (`EACCES`).
