## Проверки

Базовый набор повторяет CI. CI запускает его на Ubuntu с Node.js 22 и 24. Для тестов нужен доступный из Node.js интерпретатор `python` на Windows или `python3` на других системах. На этой машине npm запускается через `node local/temp/rezak-npm-cli-11/package/bin/npm-cli.js`.

| --- | --- | --- | --- |
| Установка | `npm ci --no-audit --no-fund` | Зависимости установлены из lockfile | Прошла |
| Поиск секретов | `npm run check:secrets` | Сканер завершился с кодом 0 | Прошла, проверено 152 файла |
| Проверка типов | `npm run typecheck` | TypeScript завершился с кодом 0 | Прошла |
| Модульные и сервисные тесты | `npm test` | Все тесты завершились успешно | Прогон остановился на XML-тестах с ошибкой запуска `python3` (`EACCES`) |
| Сборка | `npm run build` | TypeScript и Vite завершились с кодом 0 | Прошла |

Для быстрой обратной связи подходят проверка типов и тесты затронутого модуля. Перед готовностью PR предлагается выполнить весь набор. Линтер, общий браузерный E2E, CRAP и мутационное тестирование отсутствуют в текущем CI.

Пользователь подтвердил, что для каждого изменения поведения нужно писать автоматические тесты по ходу реализации. В спецификации сопоставляем проверяемые требования с тестами и включаем обычные сценарии, ошибки и граничные случаи. Для исправления дефекта добавляем регрессионный тест. Сторонние сервисы в штатном прогоне заменяем имитациями, а результаты проверок с реальными аккаунтами фиксируем отдельно.

## Доставка

Текущая работа ведётся локально в `fossko_changes`. Если пользователь решит отправить изменения автору, целевая ветка — `ilyahov/rezak:main`. Предлагаемый порядок — локальные проверки и ревью, затем черновик PR после отдельного решения о публикации. Обязательность проверок GitHub, ответственный за ревью и способ слияния остаются открытыми до решения о публикации.
