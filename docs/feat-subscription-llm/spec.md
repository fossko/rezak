## Подключение в настройках

**R1 (O1).** В существующей вкладке «ИИ (LLM)» добавить пункт «Подключить подписку» с выбором поставщика. Для каждого показывать статус и инструкцию на русском. Доступные действия соответствуют статусу: начать вход, отменить, повторить или отключить. Если поставщик использует отдельный браузер и одноразовый код, показывать ссылку только из официального сеанса и пояснять, где ввести код. Для браузерного OAuth открывается официальная страница согласия. Браузерное подтверждение само по себе не означает, что Rezak может использовать аккаунт: статус «Подключено» выставляется после проверки соответствующим адаптером.

**R2 (O1, O2).** Для OpenAI предлагается официальный Sign in with ChatGPT для стороннего приложения. Штатный `codex login --device-auth` авторизует установленный CLI и документируется как отдельный сценарий. Применимость предварительной интеграции, регистрацию приложения, доступные аккаунты и модели нужно подтвердить до реализации. Если доступ получен, использовать официальный поток для Rezak и поддерживаемый интерфейс вывода модели, совместимый с задачами редактора. Обязательная приёмка — одна существующая ИИ-операция Rezak с реальной подходящей подпиской. [Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server), [пределы предварительного доступа](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).

**R3 (O1, O2).** Для Claude Code показывать отдельную инструкцию по штатному `claude auth login`: открыть адрес из официального клиента и завершить вход в браузере или вернуться с кодом в терминал, если его запросит сам CLI. Проверка использования Claude Code для ИИ-операции Rezak является условной. Интеграция допустима только при подтверждении применимости условий Anthropic к этому сценарию с официальным неизменённым клиентом. Пока это не подтверждено, вариант в настройках показывает инструкцию и сообщает, что выполнение операций по подписке Claude недоступно. [Вход Claude Code](https://code.claude.com/docs/en/authentication), [условия Anthropic](https://code.claude.com/docs/en/legal-and-compliance).

## Выполнение операций и данные

**R4 (O2).** Существующие операции Rezak выбирают маршрут по явно выбранному режиму. Сохраняются интерфейс вызова ИИ-операции, отмена и контракт результата. Адаптер подписки преобразует ошибки поставщика в состояния «Требуется вход», «Подписка недоступна» или ошибку операции. При истечении авторизации пользователь получает действие для повторного входа. Лимит подписки или сбой входа не переключает запрос на платный API. Существующие настройки OpenAI-совместимого API сохраняют работоспособность.

**R5 (O3).** Для первой версии предлагается локальный компонент на компьютере пользователя. Он выполняет поддерживаемый обмен авторизацией или обращается к официальному CLI, если сценарий разрешён поставщиком. Браузер получает состояние подключения и результат операции. Секреты остаются в защищённом локальном хранилище, предусмотренном выбранной интеграцией. Их нельзя передавать в хранилище браузера, диагностические события, сервер рабочих пространств или в файлы проекта. Локальный интерфейс ограничивается запросами экземпляра Rezak, проверяет источник и принимает только фиксированные операции. Текст проекта передаётся выбранному поставщику при явном запуске ИИ-операции. При отключении сеанс очищается в пределах системы авторизации выбранного поставщика.

Точки встраивания — [настройки ИИ](../../src/ui/LlmSettings.tsx) и [клиент ИИ-операций](../../src/llm/client.ts). Локальный компонент позволяет работать с официальным процессом и хранить авторизацию отдельно от браузерных данных Rezak. Вариант, в котором Rezak извлекает учётные данные CLI, исключён из проекта. Общедоступное размещение компонента и аккаунты на сервере рабочих пространств выходят за рамки первой версии.

## Приёмка и тесты

| Требование | Автоматическая проверка | Ожидание |
| --- | --- | --- |
| R1 | Браузерный тест настроек с имитацией состояния локального компонента | Пункт доступен, русская инструкция соответствует поставщику и состоянию. Отмена возвращает исходное состояние |
| R2 | Контрактные тесты адаптера OpenAI с имитацией разрешённого официального потока | Корректные события переводят подключение в рабочее состояние. Отмена, отказ и неподдерживаемый аккаунт дают понятное состояние |
| R3 | Браузерный и контрактный тесты доступности Claude Code | До подтверждения интеграции показывается инструкция и отсутствует выполнение операций по подписке. При подтверждении добавить успех, ошибки и повторный вход |
| R4 | Интеграционные тесты действующей ИИ-операции с имитациями подписки и API | Результат обрабатывается штатно, отмена завершает запрос, истечение входа и лимит подписки не вызывают API. Явно выбранный API работает как прежде |
| R5 | Тесты локального интерфейса и фиктивных учётных данных | Посторонний источник отклонён, тестовые секреты отсутствуют в ответах состояния, логах и экспорте |

Ожидания берутся из согласованных переходов состояний и формата существующей операции. Штатный CI использует имитации ответов. Перед объявлением режима доступным провести отдельную проверку с реальной подпиской поставщика. Дополнительно выполнить [проверки профиля CI](../sdlc/project.md).

## Решения до реализации

Подтвердить применимость Sign in with ChatGPT и допустимый сценарий Claude Code. Если Anthropic не подтверждает использование подписки для операций Rezak, согласовать выпуск Claude Code в режиме инструкции. Профиль SDLC и постановка остаются черновиками. Изменения интерфейса ограничены настройками подключения.
