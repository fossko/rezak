# Использовать подписки ChatGPT и Claude в Rezak

- Идентификатор задачи: `subscription-llm`
- Ревизия: 3
- Статус: черновик
Принятая ревизия: —

## Зачем

Пользователь хочет запускать существующие ИИ-операции Rezak со своей подпиской ChatGPT или Claude. Сейчас [клиент Rezak](../../src/llm/client.ts) обращается к настраиваемому API и при наличии ключа добавляет его в заголовок авторизации.

## Желаемые результаты

- **O1.** В настройках Rezak есть пункт «Подключить подписку». Пользователь выбирает Codex или Claude Code и получает инструкцию на русском: где открыть официальную страницу входа и в каком окне подтвердить подключение. Если поставщик выдал одноразовый код, инструкция указывает адрес текущего сеанса и место ввода кода.
- **O2.** Для каждого поддержанного подписочного режима пользователь может выполнить существующую ИИ-операцию Rezak со своего аккаунта. Истёкшая авторизация приводит к сообщению с инструкцией по повторному входу. Переключение на платный API требует явного выбора пользователя.
- **O3.** Способ входа и использования подписки соответствует документации поставщика. Ключи и токены не попадают в Git, логи, экспорт проекта или данные рабочего пространства.

## Подтверждённые способы и вопросы к спецификации

- **Codex.** Для официального CLI доступен обычный `codex login` и вход по коду через `codex login --device-auth`. Для последнего пользователь включает вход по коду в настройках безопасности ChatGPT и открывает ссылку из терминала. OpenAI отдельно документирует предварительный механизм Sign in with ChatGPT для приложений с Codex app-server. В спецификации нужно проверить доступность и ограничения этого механизма для Rezak. [Вход Codex](https://learn.chatgpt.com/docs/auth), [интеграция Codex app-server](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server).
- **Claude Code.** Для официального CLI пользователь выполняет `claude auth login` и выбирает аккаунт Claude в браузере. Если официальный браузерный сценарий показывает код, пользователь вводит его в терминал Claude Code. Anthropic ограничивает авторизацию через Claude.ai в сторонних приложениях и посредничество при использовании подписки. До реализации нужно определить, подходит ли Rezak разрешённый сценарий с официальным неизменённым клиентом. [Вход Claude Code](https://code.claude.com/docs/en/authentication), [условия интеграции Anthropic](https://code.claude.com/docs/en/legal-and-compliance).

## Границы задачи

Пользователь подтвердил отдельный пункт «Подключить подписку» в настройках. Первую версию предлагается рассматривать для локального Rezak. Изменения интерфейса ограничены настройками подключения. В спецификации нужно определить, какие шаги выполняются из Rezak и какие выполняет официальный клиент. Задача исправления уязвимостей ведётся отдельно.

## Автоматические тесты

- **O1.** Проверить наличие пункта в настройках, выбор поставщика и правильную инструкцию для каждого поддержанного сценария входа.
- **O2.** Проверить успешное подключение и выполнение ИИ-операции, отмену и ошибки входа, истечение авторизации и повторный вход. Проверить, что переход на оплату через API происходит только после явного выбора.
- **O3.** Проверить, что диагностические сообщения и экспортируемые данные не содержат учётных данных. В автоматических тестах использовать имитации ответов поставщиков, чтобы прогон не требовал реальной подписки.
