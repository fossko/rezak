# Ревью инструкций подключения подписок

- База: `3f5f62504c4364a1ebc9edd2ba1762210aed0b99`
- Проверенный коммит: `339266a1d1998521a3847a3fc6b582ffaffd7a14`
- Источники: [постановка 4](intent.md), [спецификация 3](spec.md), [план 1](plan.md), [правила репозитория](../../AGENTS.md)

**Соответствие постановке и спецификации.** T01 закрывает согласованную часть O1/R1. Кнопка доступна во вкладке «ИИ (LLM)». Обе инструкции описывают команды и работу с кодами по документации поставщиков. Браузерный тест проверяет раскрытие с клавиатуры, состояние кнопки, команды, ссылки, сворачивание, неизменность сохранённых настроек и отсутствие обращений к поставщикам.

**Корректность и безопасность.** Новое состояние живёт в компоненте настроек, идентификатор раскрываемой области создаётся через `useId`. Обработчик кнопки меняет только видимость инструкций. Официальные ссылки открываются по явному действию пользователя и используют `noreferrer`. Код ввода ключей, сетевых запросов и хранения учётных данных не изменён. Блокирующих замечаний при саморевью не найдено.

Проверка сделана отдельным проходом после реализации тем же агентом. [Результаты тестов](execution.md).

## Ревью локального входа ChatGPT

- База: `2ca2294ccb184f5f484b343eae133e940897cdb0`
- Проверенная версия после правок: `1350a5f0ac52010220b2a9620905c9623c36f2ad`
- Источники: [сценарий входа 2](browser-sign-in.md), [T02](tickets/T02.md), [результаты проверок](execution.md)

**Соответствие.** Сервисный тест подтверждает C1–C4 через HTTP и имитацию OpenAI с подписанным тестовым ID-токеном. Браузерный тест проходит через настройки, выбирает модель и получает итог штатной проверки ИИ-подключения. Подтверждение реального тарифа и доступности модели ожидается.

**Корректность и безопасность.** Проверены loopback и источник POST, одноразовое состояние callback, PKCE, nonce, подпись, полученное разрешение, отсутствие токенов в клиентском ответе и выключение режима API при выборе подписки. Ревью обнаружило, что уже отправленный запрос мог продолжиться после отключения подписки. Исправление отменяет начатые запросы и блокирует параллельную замену сессии во время обмена кода. Повторный прогон подтвердил исправление. Блокирующих замечаний по локальной реализации больше не найдено. Реальная приёмка всё ещё открыта.

Реализацию и ревью выполнил один агент в отдельных проходах.
