# Ревью инструкций подключения подписок

- База: `3f5f62504c4364a1ebc9edd2ba1762210aed0b99`
- Проверенный коммит: `339266a1d1998521a3847a3fc6b582ffaffd7a14`
- Источники: [постановка 4](intent.md), [спецификация 3](spec.md), [план 1](plan.md), [правила репозитория](../../AGENTS.md)

**Соответствие постановке и спецификации.** T01 закрывает согласованную часть O1/R1. Кнопка доступна во вкладке «ИИ (LLM)». Обе инструкции описывают команды и работу с кодами по документации поставщиков. Браузерный тест проверяет раскрытие с клавиатуры, состояние кнопки, команды, ссылки, сворачивание, неизменность сохранённых настроек и отсутствие обращений к поставщикам.

**Корректность и безопасность.** Новое состояние живёт в компоненте настроек, идентификатор раскрываемой области создаётся через `useId`. Обработчик кнопки меняет только видимость инструкций. Официальные ссылки открываются по явному действию пользователя и используют `noreferrer`. Код ввода ключей, сетевых запросов и хранения учётных данных не изменён. Блокирующих замечаний при саморевью не найдено.

Проверка сделана отдельным проходом после реализации тем же агентом. [Результаты тестов](execution.md).
